# vinibaggio-dotfiles

Personal dotfiles and bootstrap scripts.

## What belongs in git

Track files that are:
- intentional
- portable across machines
- human-authored
- stable over time
- part of the desired environment setup

Examples in this repo:
- `zsh/zshrc`
- `bashrc`
- `config/git/config`
- `config/wezterm/wezterm.lua`
- `config/karabiner/karabiner.json`
- `brewfiles/Brewfile`
- install scripts

## What does not belong in git

Ignore files that are:
- secrets or tokens
- auth/session state
- machine-specific
- generated by applications
- caches, logs, update metadata, or backups
- frequently rewritten by tools

Examples ignored in this repo:
- `config/gh/hosts.yml`
- `config/rclone/rclone.conf`
- `config/op/config`
- `config/op/plugins/used_items/`
- `config/planetscale/state.yml`
- `config/fish/fish_variables`
- `config/fish/completions/`
- `config/karabiner/automatic_backups/`
- `config/.wrangler/`
- `config/raycast/extensions/`
- `config/iterm2/AppSupport`

## Rule of thumb

Ask:

1. **If I clone this on a new machine, do I want this exact file restored?**
   - If yes, track it.
   - If no, ignore it.

2. **Did I write this, or did the app write this?**
   - If I wrote it, it is a good candidate for git.
   - If the app wrote it, it is probably local state.

The goal is to version the desired behavior, not the machine residue.

## Secrets

Secrets should not be committed to this repo.

Current shell setup expects the LM Studio token in 1Password at:
- Vault: `Private`
- Item: `LM_API_TOKEN`
- Field: `credential`

The token is loaded in shell via `op read`.
